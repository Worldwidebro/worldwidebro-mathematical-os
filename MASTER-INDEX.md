## System Architecture

```
STRATEGY (Planning)
    ↓
INFRASTRUCTURE (Tech Stack)
    ↓
VENTURES (Execution)
    ↓
REFERENCE (Learning)
    ↓
(Loop back to STRATEGY)
```

Each orb links to the other 3. Everything connects.

---

## How The System Works

1. **STRATEGY** decides which sector/venture to build
2. **INFRASTRUCTURE** provisions the tech stack needed
3. **VENTURES** executes the venture, logs decisions + learnings
4. **REFERENCE** captures patterns + components for reuse
5. Loop back: New ventures learn from old ones
