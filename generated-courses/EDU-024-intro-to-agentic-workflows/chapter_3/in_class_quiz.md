# Quiz: Chapter 3: Practical Application Cases

1. What is the primary benefit of active recall over passive review?
   A) Passive review is faster but yields 50% lower long-term retention. (Correct)
   B) Passive review has no difference.
   C) Active recall increases cognitive fatigue without benefits.

2. How does spacing affect learning consolidation?
   Answer: Spacing allows memory traces to decay slightly, making retrieval more effortful and strengthening retention.
