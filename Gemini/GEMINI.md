# GEMINI CONTEXT: Worldwidebro Holdings AI Operating System

## CORE THESIS
We are NOT building 712 isolated ventures. We are building a **delegation network** where ventures power each other. Work flows downstream, margins flow upstream, data flows everywhere. Every venture must both RECEIVE work from and SEND work to at least 2 other ventures. Arbitrage happens at every handoff.

## LOCATION
Primary market: Charlotte, NC (Mecklenburg County). Scaling nationally.

## TECHNICAL STACK
- **Knowledge Graph**: Neo4j (relationships, delegation flows, agent reasoning)
- **Transactional DB**: Supabase/PostgreSQL (money, compliance, structured data)
- **Document Store**: GitHub/Obsidian (playbooks, rules, agent training data)
- **Orchestration UI**: vex (Next.js 14 + Tailwind) — real-time delegation dashboard
- **AI Agents**: MCP-based agents with skill inventories, decision authority levels
- **Automation Tools**: Fractal (venture spawning), SkillOpt (skill optimization), Loop Engineering (workflow loops), Evolver (continuous improvement)

## DELEGATION RULES (Non-Negotiable)
- Every venture must delegate work to ≥2 other ventures.
- Every handoff captures margin (30-40% STA, 25-35% CON, 8-12% RE, 1-2% FIN advisory, 5-10% OPS).
- Delegation SLA: 24h response, 72h completion.
- All delegation events logged in Neo4j. All transactions logged in Supabase.
- Bottlenecks trigger Loop Engineering optimization.
- Skill gaps trigger SkillOpt training workflows.
- Zero-cost priority: We always select free, self-hosted, open-source services to avoid overhead.

## DECISION AUTHORITY
- **Level 1 (Agent Autonomous)**: < $5k, routine operations.
- **Level 2 (Human-in-Loop)**: $5k-$50k, non-standard decisions.
- **Level 3 (Executive)**: > $50k, M&A, pivots, new ventures.
