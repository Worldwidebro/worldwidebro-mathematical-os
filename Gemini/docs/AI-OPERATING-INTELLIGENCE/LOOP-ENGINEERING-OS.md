# MASTER EXECUTION LOOP

## Step 1 — Goal Creation
Input: CEO Agent identifies objective.
Example: "Increase Construction OS revenue from $5K/month to $20K/month"
Output: Strategic Goal

---

## Step 2 — Task Generation
System analyzes:
Current state → Desired state → Capability gaps
Creates:
Initiatives → Tasks → Subtasks

---

## Step 3 — Agent Assignment
Policy Agent evaluates:
Task requirements, Available agents, Historical performance, Skill availability.
Selects: Best agent.

---

## Step 4 — Skill Selection
Agent asks: "What capability is required?"
Examples:
- Task: Create payment system → Required skill: Stripe integration
- Task: Acquire customers → Required skill: Outbound sales automation

Skill score = Capability fit + Past success + Speed + ROI

---

## Step 5 — Execution
Agent executes through n8n workflows.
Examples: API calls, CRM updates, Emails, Code deployment, Research.

---

## Step 6 — Observation
System records: Completion, Time, Cost, Errors, Revenue impact, Customer response.
Stored in: Metabase, Neo4j, Mem0.

---

## Step 7 — Learning
System asks: What worked? What failed? What should change?
Creates: Improved skill ranking, Better workflows, New knowledge.

---

## Step 8 — Optimization
Next execution becomes: Faster, Cheaper, Higher quality, More autonomous.
