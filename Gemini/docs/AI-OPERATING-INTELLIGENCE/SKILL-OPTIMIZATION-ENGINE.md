# SKILL OPTIMIZATION ENGINE

# Purpose

Determine the highest-performing capability for every task.

---

# Skill Selection Algorithm

Input:
- Task
- Requirements
- Available Skills

Evaluate:
1. Capability Match
2. Historical Success
3. Execution Speed
4. Cost
5. Revenue Impact

Formula:
Skill Score = Capability Fit + Success Rate + ROI - Cost

---

# Skill Memory

Track:
- Skill
- Agent
- Task
- Outcome
- Revenue Impact
- Success Rate

---

# Example

- **Task**: Build landing page
- **Skills available**:
  - *Skill A*: Success 90%, 8 hours
  - *Skill B*: Success 60%, 20 hours
- **Selection**: Choose Skill A
