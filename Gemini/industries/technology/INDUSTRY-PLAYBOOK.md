# TECHNOLOGY (TECH) Industry Playbook

## Core Mission
Deliver core software operations infrastructure, AI model routing systems, and automated code security scanning to all ventures, cutting API costs and ensuring developer compliance.

## Who We Need (Inputs)
- **FINANCIAL**: Provides R&D capital, token budgets, and investment gates.
- **OPERATIONS**: Audits SLA governance, privacy, and regulatory compliance.

## Who We Serve (Outputs)
- **ALL 13 SECTORS**: We supply headless checkouts (Next.js/Vite), custom RAG vector collections (Qdrant), relational ledger routing, and codebase audits (GitNexus).

## Delegation Handoff Rules
1. **Receive Request**: Any venture submits software or codebase audit requests.
2. **Execute (SLA < 24h)**: Auto-provision staging repositories or deploy MCP gateways.
3. **Optimizations**: Apply token compression routing via LiteLLM to reduce LLM overhead by 90%.
4. **Margin Capture**: Invoice flat monthly retainers or 5-10% of code project value.

- **Capabilities**: devtools, mcp, database, security, rag
