# MARKETPLACE (MKT) Industry Playbook

## Core Mission
Deliver multi-vendor transaction checkout systems, split carts, and product listing platforms to facilitate commerce between ventures and clients.

## Who We Need (Inputs)
- **TECHNOLOGY**: Provides checkout forms, security tokens, and hosting APIs.
- **STAFFING**: Provides catalog managers, customer service agents, and support staff.
- **MEDIA**: Drives buyer attention and SEO lead funnels.

## Who We Serve (Outputs)
- **CONSTRUCTION/STAFFING/REAL ESTATE**: We provide transaction checkouts and pricing lists.

## Delegation Handoff Rules
1. **List Product**: Seller uploads catalog → Parse metadata and verify (SLA < 10 mins).
2. **Execute Split**: Customer checks out → Split payments via Stripe to multiple ventures.
3. **Margin Capture**: 2-5% transaction fee on external checkouts.

## Technology Stack
- **Primary**: MedusaJS · Next.js · Stripe SDK · PostgreSQL
- **Capabilities**: checkout, split-payments, seller-portals, inventory

## KPI Targets
- Checkout Success: > 99.5%
- Cart Abandonment Rate: < 65%
- Transaction Processing Time: < 2s
