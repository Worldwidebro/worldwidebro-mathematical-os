# TRANSPORTATION (TRA) Industry Playbook

## Core Mission
Deliver real-time load dispatching dashboards, driver routing checklists, and automated carrier communications to eliminate empty backhauls.

## Who We Need (Inputs)
- **STAFFING**: We rely on STA for CDL drivers, dispatch coordinators, and mechanics.
- **CONSTRUCTION**: Provides fleet maintenance yards and heavy equipment depots.
- **MARKETPLACE**: Provides the dispatch routing API and shipping order checkouts.

## Who We Serve (Outputs)
- **CONSTRUCTION/REAL ESTATE**: We provide heavy equipment transport and building material deliveries.
- **HOSPITALITY**: We provide logistics and catering supply run deliveries.

## Delegation Handoff Rules
1. **Receive Order**: Shipper requests transport → Match carrier and route (SLA < 15 mins).
2. **Dispatch Driver**: Send booking confirmation and GPS route via SMS (SLA < 30 mins).
3. **Margin Capture**: 10-15% arbitrage markup on carrier freight costs.

## Technology Stack
- **Primary**: Temporal · Python (Shutil) · Paddle-OCR · PostgreSQL
- **Capabilities**: routing, dispatching, ocr-parsing, SMS-notifications

## KPI Targets
- Empty Miles (Deadhead): < 10%
- On-Time Delivery: > 96%
- Rate Sheet Parsing Time: < 10s
