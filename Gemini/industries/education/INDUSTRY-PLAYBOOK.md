# EDUCATION (EDU) Industry Playbook

## Core Mission
Deliver AI-native developer training, `.cursorrules` configuration files, and automated coding tutor Sandboxes (CubeSandbox) to build a pre-vetted workforce.

## Who We Need (Inputs)
- **STAFFING**: We need tutors, course coordinators, and grading contractors.
- **TECHNOLOGY**: We need Sandbox environments, code runtimes, and learning platforms.
- **MEDIA**: We need video distribution and content production assets.

## Who We Serve (Outputs)
- **STAFFING**: We feed certified junior developers and interns into the placement pool.
- **OPERATIONS**: We provide regulatory training, onboarding modules, and compliance lessons.

## Delegation Handoff Rules
1. **Talent Output**: Candidate completes course → Emit capability credentials to STA.
2. **Setup Tutor**: Developer requests code sandbox → Deploy CubeSandbox instance (SLA < 15s).
3. **Margin Capture**: Sell coursework PDFs ($29-$49) or premium coding cohorts ($1,500/seat).

## Technology Stack
- **Primary**: CubeSandbox · Syncthing · Replit API · Markdown
- **Capabilities**: sandboxing, training, content-generation, auth

## KPI Targets
- Course Completion: > 80%
- Sandbox Provisioning: < 15s
- Talent Placement Rate: > 60% within 30 days
