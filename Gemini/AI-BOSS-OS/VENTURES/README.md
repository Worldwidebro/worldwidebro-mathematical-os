# VENTURES LAYER
## Individual Venture Configurations, Templates, and Registries

---

## 1. Purpose
This directory maps individual venture startups in the portfolio and houses templates used by the Venture Factory (`create_venture.py`) when spawning new businesses.

## 2. Directory Mappings
In the unified Civilization OS, all venture configurations inherit from the parent platform services (IZA OS, Medusa Commerce, Stripe, n8n):
- `AI-Healthcare-001/`: Startup 001. Configures the clinical scheduling and RAG pipeline.
- `AI-Finance-002/`: Startup 002. Configures the automated tax optimization rules.
- `AI-Retail-003/`: Startup 003. Configures Medusa storefront endpoints.

## 3. Required Startup Templates
Every spawned venture must contain the following core strategic documents in its directory:
* `COMPANY.md`: Executive overview, contact keys.
* `BUSINESS-PLAN.md`: Target audience and TAM validation checks.
* `PRD.md`: Product Requirements Document for the initial MVP.
* `FINANCIAL-MODEL.md`: Treasury allocations, budget limit policies.
* `MARKETING.md`: Creator networks, newsletter campaigns.
* `OPERATIONS.md`: Assigned agent workforce profiles.
* `ROADMAP.md`: Release schedules, sprint goals.
