# Product Validation: TikTok-Driven Lean Testing System

This document outlines the lean product validation protocol. Before committing engineering, capital, or supply chain resources, we use organic attention to test actual purchase intent.

---

## 1. The Validation Flow

We validate products using three progressive micro-tests:

```text
100 Organic Videos ➔ Click-Through Test ➔ Fake Door / Presell checkout ➔ Scale Decision
```

- **Phase 1: Organic Reach Test**: Run 25-50 videos talking about the product concept (e.g. showcasing a dashboard interface or Obsidian workspace).
- **Phase 2: Intent Test (Clicks)**: Measure profile clicks and lead-magnet signup volume. If CTR to the landing page is < 2%, the concept is rejected.
- **Phase 3: Financial Test (Conversions)**: Implement a "Presell" button or $29 digital template purchase. If checkout conversion is > 1.5%, the opportunity is validated for scaling.

---

## 2. Validation Metrics Scorecard

Every validation run is evaluated in our Commerce Engine dashboard using the following checklist:

- **Videos Published**: Minimum 25 videos over 14 days.
- **Total Views**: Target > 1.0M views cumulative.
- **Unique Profile Clicks**: Target > 5,000 profile visitor actions.
- **Conversions / Purchases**: Target > 200 orders or signups.
- **Opportunity Score Matrix**:
  - **Score < 40**: *Discard*. Archive content and redirect links to high-margin affiliates.
  - **Score 40-70**: *Pivot*. Adjust hooks, modify the landing page, or bundle with another template.
  - **Score > 70**: *Scale*. Re-compile as an owned venture under AI Boss Holdings (Venture Factory).
