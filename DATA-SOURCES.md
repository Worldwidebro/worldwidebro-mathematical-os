## 11. HOW TO SYNC DATA (THE PIPELINE)

### Standard Sync Workflow
```
Step 1: Update CSV files
  ├─ ventures-master.csv (manually or via API)
  ├─ ventures_with_capabilities.csv (derive from ventures-master)
  └─ MASTER-REPO-REGISTRY.csv (manually or via GitHub API)

Step 2: Populate Knowledge Graph
  └─ python3 populate_venture_knowledge_graph.py
     ├─ Reads: CSVs
     ├─ Writes: Supabase (graph_entities, graph_relationships)
     └─ Creates: Risk detection, relationship inference

Step 3: Sync to Obsidian
  └─ python3 obsidian_graph_sync.py
     ├─ Reads: Supabase
     ├─ Writes: .planning/graph-data.json, .planning/venture-hub-alignment.json
     └─ Renders: KNOWLEDGE-GRAPH-DASHBOARD.md (Dataview blocks)

Step 4: Export Analytics
  └─ Query DuckDB for dashboards
     └─ duckdb worldwidebro_os.duckdb "SELECT ..."

Step 5: (Optional) Sync to External Systems
  ├─ Slack (venture updates)
  ├─ Email (reports)
  └─ External BI tools (Grafana, Tableau, etc.)
```
