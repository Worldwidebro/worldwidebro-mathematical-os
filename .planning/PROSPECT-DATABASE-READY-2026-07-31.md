```

Duke Health,Lab Director,Lab Director,lab@duke.edu,(919) 684-8111,LT-005,Cold-chain delays,Same-day STAT courier,[script],2000-3000,not_contacted,memory,2026-07-31
SYNCON Construction,Project Manager,Project Manager,pm@syncon.com,(704) 555-0101,OPS-001,Crew shortages,Pre-vetted crew dispatch,[script],3000-7000,not_contacted,memory,2026-07-31
...
```

### Supabase Table Structure

```sql
CREATE TABLE prospect_database (
  id UUID PRIMARY KEY,
  venture_id VARCHAR(20),
  company_name VARCHAR(255),
  contact_name VARCHAR(255),
  contact_role VARCHAR(100),
  contact_email VARCHAR(255),
  contact_phone VARCHAR(20),
  pain_point TEXT,
  value_prop TEXT,
  revenue_target VARCHAR(50),
  status VARCHAR(20), -- not_contacted, contacted, demo, customer
  call_date TIMESTAMP,
  notes TEXT,
  priority VARCHAR(10), -- HIGH, MEDIUM, LOW
  source VARCHAR(50), -- memory, USASpending, Etsy, LinkedIn, MLS
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
```
