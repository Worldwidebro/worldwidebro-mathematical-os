**Pilot Venture(s):**
- **Primary:** LT-005 (Medical Courier Dispatch, 12.2%, validation) — premium rates, recurring B2B, regulatory moat
- **Secondary:** LT-003 (General Logistics Dispatch, 22.8%) + LT-002 (Freight Brokerage, 12.2%)

**Funding Sources (Priority):**
1. **Equipment Financing** (Coypu, Guideline, USDOT-approved lenders) — $50–200K for 5–20 vehicle fleet
2. **SBA 7(a) Loans + DOT Grants** — $50–150K combined non-dilutive
3. **Supply Chain VCs** (Plug & Play, Containers VC, Initialized) — $100–300K conviction + ops expertise
4. **Angel Networks (ex-Uber Freight, XPO, J.B. Hunt)** — $30–75K + deep ops validation
5. **Freight Broker Partnerships** (Echo Global, Landstar model) — $50–100K revenue share + working capital

**Compliance Roadmap:**
- **Months 1–2:** 
  - USDOT registration + MC (Motor Carrier) number (30 days, ~$300)
  - CDL for pilot drivers (60 days, ~$500)
  - DOT medical certification (30 days, ~$150/driver)
- **Months 2–3:**
  - Commercial auto insurance ($2–5K/year for 5-vehicle fleet)
  - Cargo/liability insurance ($1–3K/year, medical premium)
  - State intrastate permits (~$200)
- **Months 3–4:**
  - HIPAA compliance audit if medical (if LT-005, $5–10K one-time)
  - Background checks + driver screening ($50/driver)
  - Hazmat certification if needed ($100/driver)
- **Q3:** Full regulatory compliance + live operations

**Capital Target:** $50–100K seed, $200–300K by EOQ (fleet expansion)

**Revenue Path:**
- Month 3: $3–5K/mo (5 vehicles, ~50 deliveries/day, $2–4/mile premium)
- Month 6: $12–18K/mo (10–15 vehicles, hospital contracts live)
- Q3 close: $20–30K/mo run rate → Series Seed ($300–500K) for 20–30 vehicle expansion

**Key Actions:**
- Fleet strategy: Buy used 5–7 vans ($8–12K each = $40–60K)
- Target: Hospitals, labs, pharmaceutical (non-consumer, recurring, $1–2K MRR contracts)
- Build: Telematics + dispatch software (Samsara integration or custom)
- Hire: 1 ops manager (ex-Uber Freight or local carrier) + 1 engineer
- Partnerships: Cerner, Epic, Allscripts API for hospital system dispatch

**Risk Flags:**
- ⚠️ **Capital intensity:** 2–3x more working capital than FIN/CON; vehicle acquisition is fixed cost
- ⚠️ **Driver churn:** 30–40% annual turnover industry standard; recruiting/retention ongoing
- ⚠️ **Margin compression:** Uber Freight, Amazon Logistics copy model; density + routing matter
- ⚠️ **Fuel sensitivity:** Crude price swings 20–30%; kills profitability if margin is 15–20%
- 🟡 **Growth ceiling:** Can scale to $500K–$1M/mo MRR, but not SaaS-like returns; asset-heavy
