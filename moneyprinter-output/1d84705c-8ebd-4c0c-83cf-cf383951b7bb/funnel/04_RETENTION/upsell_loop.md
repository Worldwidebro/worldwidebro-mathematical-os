# Retention + Upsell — Building Supply Chain

## Loop
```
Purchase / signup
    → Activate (first workflow live in 7 days)
    → Expand (second trade / second job)
    → Refer (case study or intro bonus)
```

## Triggers
- 30 days active → offer advanced module
- NPS 9–10 → ask for testimonial (feeds BOF)
- Churn risk → MOF re-engagement content

## KPI
activation_rate | expansion_revenue | referral_rate
