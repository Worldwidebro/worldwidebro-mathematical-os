# Brand Identity — Permit Compliance Platform

## Positioning
> We help **Commercial GCs and specialty contractors** achieve **Predictable jobs and audit-ready workflows** without **spreadsheet chaos and blind spots**.

## Tone
**Primary:** technical, direct  
**Secondary:** confident, no hype

## Visual system
- **Primary:** `#0B1F33` (navy)
- **Accent:** `#2ECC71` (action / proof)
- **Type:** Bold sans headlines, readable body
- **Content design:** Text-on-card reels, dashboard screenshots for MOF

## Proof style
- Before/after timelines
- Dashboard screenshots
- Short contractor quotes (verify before BOF publish)

## Narrative
1. **Why we exist:** Construction ops shouldn't run on fifteen tabs.
2. **Why now:** Margins are thin; delays are expensive.
3. **Why trust us:** Built for field reality, not generic SaaS demos.

## Cross-stage check
- [ ] TOF hooks match tone
- [ ] MOF demos use same colors/type
- [ ] BOF offer uses same proof style
