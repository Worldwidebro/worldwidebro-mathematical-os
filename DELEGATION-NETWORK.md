# DELEGATION NETWORK

The map of how 6 OPCOs power each other through delegation, work flow, and capital cycles.

---

## Core Network (5-Step Cycle)

```
STAFFING (STA) → CONSTRUCTION (CON) → REAL ESTATE (RE) → FINANCE (FIN) → TECHNOLOGY (TECH)
                                                                                      ↓
                                                                                 (back to STA)
```

**Margin Extraction:**
- STA: Contractor $30/hr → $40/hr (+$10/hr margin) → Sell to CON
- CON: Labor $40/hr × 100hrs = $4K cost → Bill $60/hr = $6K revenue → $2K margin
- RE: Property mgmt $2K/mo cost → $3K/mo charge → $1K margin
- FIN: Borrow @8% → Lend @10% → 2% spread margin
- TECH: Saves labor → Charges implementation fee

## Value Flows Per OPCO

**STA (Staffing):** $22K/mo revenue, $18K labor costs = $4K margin (18%)
**CON (Construction):** $22K/mo revenue, $18K costs = $4K margin (18%)
**RE (Real Estate):** $8K/mo revenue, $6.5K costs = $1.5K margin (19%)
**FIN (Finance):** $4K/mo revenue, $2.5K costs = $1.5K margin (38%)
**TECH (IZA OS):** Powers all, cost allocation across OPCOs
