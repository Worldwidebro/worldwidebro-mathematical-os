# Screening Form — Driver Knockout Questions

*Build in Jotform or Google Forms. Auto-reject on any disqualifying answer. Goal: 2 minutes, filters before you spend time on a call.*

---

## Questions

1. **Full name** — short text
2. **Phone + email** — short text
3. **Are you 21 or older?** — Yes / No → *No = reject*
4. **Do you have a valid driver's license?** — Yes / No → *No = reject*
5. **Years of driving experience** — 0–1 / 2–4 / 5+ → *0–1 = reject*
6. **In the last 3 years, any DUI, reckless driving, or license suspension?** — Yes / No → *Yes = reject*
7. **Do you have a reliable, insured vehicle?** — Yes / No / Willing to drive a provided vehicle
8. **Do you have a smartphone?** — Yes / No → *No = reject*
9. **Can you pass a background check?** — Yes / No → *No = reject*
10. **Are you available early mornings (route start ~6–7am)?** — Yes / No / Some days
11. **Comfortable transporting biological/medical specimens following strict procedures?** — Yes / No → *No = reject*
12. **Earliest start date** — date (YYYY-MM-DD)
13. **(Optional) Prior courier or medical-transport experience?** — long text

## Auto-routing
- Any reject answer → polite decline auto-email.
- All pass → tag "Qualified," send 30-min interview booking link.

## Notes
- Keep it to one screen on mobile.
- Pipe submissions to a spreadsheet / CRM for tracking.
