## Production Workflow per Video

### Pre-Production (Day 1)
- [ ] Choose video concept from `Video-Concepts/VIDEO-IDEAS-BY-CATEGORY.md`
- [ ] Create script using `YouTube-Scripts/VIDEO-SCRIPT-TEMPLATE.md`
- [ ] Review teaching method in `Teaching-Methods/`
- [ ] Gather equipment (camera, phone, props)
- [ ] Scout location or setup area

### Recording Day
- [ ] Intro shot (5 min setup)
- [ ] Main content (vary camera angles, get close-ups)
- [ ] Multiple takes (capture different moments)
- [ ] B-roll (wide shots, reaction shots, details)
- [ ] Outro (thank you, preview next video)
- **Checklist:** Review footage quality before wrapping

### Post-Production (Days 2-3)
- [ ] Import and organize footage
- [ ] Edit: Timeline → Color → Audio → Effects
- [ ] Add music (royalty-free, kid-friendly)
- [ ] Create thumbnail
- [ ] Write description & tags
- [ ] Set publish date
- [ ] Queue for schedule upload

### Publishing
- [ ] Upload 24 hours before scheduled time
- [ ] Test links and descriptions
- [ ] Create social media preview posts
- [ ] Schedule posts for upload day + follow-up
