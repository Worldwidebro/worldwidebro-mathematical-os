# Roblox Parent & Content Guide for Age 7

## Roblox Basics for Parents

**What is Roblox?**
Roblox is a platform where users play games AND create games. Think: YouTube + Minecraft + creative tools. Millions of games built by hobbyists, developers, and studios.

**Safety First:**
- Account set to 7-year-old (restricts inappropriate content/chat)
- Parental controls enabled (limits chat, restricts games by rating)
- Play alongside Azriel frequently
- Review game ratings before playing
- Monitor playtime (20-30 min sessions)

## Roblox Studio (Building/Creating)

### Why Teach Roblox Studio?
- **Teaches:** Spatial thinking, problem-solving, creativity, persistence
- **Confidence:** Creates ownership ("I built this!")
- **Content:** Perfect for video tutorials
- **Skills:** Basic coding logic without intimidation

### Getting Started (Age 7 Version)

**What You Need:**
- Roblox Studio (free download on PC/Mac)
- Account with building privileges
- Patience (things are quirky)
- A specific goal ("Let's build a room")

**Key Concepts for Age 7:**

1. **The Workspace**
   - Parts = building blocks (cubes, spheres, cylinders)
   - Inserting parts: Click → Insert → Object
   - Moving/scaling: Click part → drag handles
   - Coloring: Part properties → Change color

2. **Simple Projects (Progression)**
   - **Week 1:** Build a simple room (4 walls, floor, ceiling)
   - **Week 2:** Add furniture (chairs, beds, decorations)
   - **Week 3:** Make parts interact (doors, platforms)
   - **Week 4:** Share creation or upload to game

3. **Basic Building Rules**
   - Use grid snapping (keeps things tidy)
   - Name parts logically (Wall1, Door, Floor)
   - Group related parts (Wall → Group)
   - Test frequently (click "Play" to see how it feels)

## Dad Teaching Moments (Roblox Focus)

**Teachable Concepts:**
- **Spatial reasoning:** "Let's think about where this goes"
- **Geometry:** Parts are shapes. What shapes do we need?
- **Planning:** "Before we build, what does our room need?"
- **Problem-solving:** "That doesn't fit. What could we try?"
- **Iteration:** "That didn't work. Let's try this."
- **Creativity:** "What would your dream room look like?"

**Key Phrases:**
- "Let's design this together"
- "What would happen if...?"
- "I like how you figured that out"
- "Let's test it and see"
- "What would you build next?"

## Common Beginner Mistakes (Learn From Them)

- **Part Clipping:** Parts overlapping makes movement weird → show proper spacing
- **Scale Issues:** Making things HUGE → explain realistic proportions
- **Missing Gravity:** Parts falling through the floor → need solid ground
- **Camera Angles:** Can't see creation properly → adjust camera view

**Video idea:** "Fail and Learn" — Show mistakes, explain fixes, celebrate learning

## Age-Appropriate Settings

**Account Settings (Parent Responsibility)**
- Go to **Settings** → **Account**
- Set birthdate to age 7 (filters content)
- Enable **Safe Chat** (limits chat to pre-approved messages)
- Disable **Trade** (prevents scams)
- Disable **Create Games** until he's ready

**Game Filtering**
- Sort games by **Most Played** and **Age 5-8** ratings
- Avoid games with E10+ or higher ratings (until supervised)
- Use **Parent** reviews on each game page

## Time Management

**Recommended Schedule:**
- **2-3 gaming sessions per week**
- **20-30 minutes per session** (sweet spot for 7-year-old)
- **Mix gameplay with building** (not just consuming)
- **Co-play first 10 minutes** (engagement + supervision)

**Warning Signs of Too Much Time:**
- Resisting breaks
- Mood changes after playing
- Neglecting other activities
- Difficulty sleeping
