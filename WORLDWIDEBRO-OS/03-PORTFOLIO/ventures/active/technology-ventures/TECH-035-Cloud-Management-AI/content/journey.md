# Journey Map - Public Infrastructure Ai

## Stages
1. Awareness - User discovers Public Infrastructure Ai
2. Intake - User submits request or inquiry
3. Triage - Team routes user to program or partner
4. Delivery - Service is provided and tracked
5. Follow-up - Team confirms outcome and next needs
6. Advocacy - User/partner shares success and refers others

## Mental Model Notes
- Users expect one clear next step at any point.
- Users assume service status should be visible after intake.
- Partners expect measurable outcomes tied to each program track.
