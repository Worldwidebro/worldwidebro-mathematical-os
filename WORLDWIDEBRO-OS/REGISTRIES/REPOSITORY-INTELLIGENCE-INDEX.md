## System Overview

**Goal:** Transform raw repositories into queryable, strategic intelligence

**Pipeline:**
```
Level 1: Raw Repos (1,400+ from GitHub)
    ↓

    ↓
Level 3: Intelligence (capabilities + dependencies + business value)
    ↓
Level 4: Embeddings (searchable semantic vectors)
    ↓
Level 5: Knowledge Graph (relationships + ecosystem)
    ↓
Level 6: Repo-to-Venture Mapping (strategic assignments)
    ↓
Level 7: Strategic Queries (decision intelligence)
```

## The 7 Layers Explained

### Layer 1: Repository Ingestion Classification
**What:** Understand repo purpose, capabilities, technical value, business value  
**Vocabulary:** Identity | Capability | Technology Stack | Business  
**Output:** Purpose, Category, Capabilities, Tech Stack, Quality, Confidence Score

### Layer 2: Venture Relevance Scoring
**What:** Score repo value for 712-venture portfolio  
**Scoring:** 6 dimensions → TIER 1-4 classification  
**Output:** Venture relevance tier + score

### Layer 3: Build vs Buy vs Wrap Decision
**What:** Decide action for each repo  
**Output:** USE | FORK | FORK+EXTEND | WRAP | COMMERCIALIZE | REBUILD | LEARN | IGNORE

### Layer 4: Ecosystem Mapping
**What:** Build relationship graph using Knowledge Graph vocabulary  
**Nodes:** REPOSITORY | VENTURE | CAPABILITY | SYSTEM | TOOL | AGENT | WORKFLOW | ASSET  
**Output:** Neo4j graph relationships

### Layer 5: Operating System Mapping
**What:** Assign each repo to OS layer  
**Layers:** 15 layers (Identity, Knowledge, Memory, Agent, Automation, Communication, Analytics, Finance, Infrastructure, Security, Data, API, Frontend, Backend, AI/ML)  
**Output:** Primary + Secondary layer assignment

### Layer 6: Technology Stack Tagging
**What:** Tag with technology vocabulary  
**Format:** Comma-separated from Technology Stack Vocabulary  
**Output:** python,fastapi,postgresql,langchain,docker

### Layer 7: Venture Factory Analysis
**What:** Identify venture candidates  
**Output:** Classification + Revenue estimate + Venture brief (if applicable)

## Vocabulary Foundation

**Reference:** [[repository-vocabulary]]

**8 Vocabulary Categories:**
1. **Identity** — Repository types (Library, Framework, Product, Platform, etc)
2. **Capability** — What it does (Authentication, Search, Analytics, RAG, Agent Framework, etc)
3. **Technology Stack** — How it's built (Python, PostgreSQL, Docker, LangChain, etc)
4. **Dependency** — Relationships (Uses, Depends On, Extends, Integrates, etc)
5. **Business** — Commercial meaning (Asset, Product, Platform, Service, Revenue Stream, etc)
6. **Venture Studio** — Strategic classification (Infrastructure, Core Platform, Product, Venture, etc)
7. **Knowledge Graph** — Graph structure (Nodes + Relationships)
8. **Build vs Buy** — Decision framework (Build, Fork, Use, Wrap, Commercialize, etc)
