## ⚙️ How It Works

### The 5 Agent Loops (Continuous Execution)

1. **Loop 1: Venture Discovery** (5 min)
   - Search 707 ventures for opportunities
   - Filter by sector, stage, health
   - Post top 20 to Slack

2. **Loop 2: Task Automation** (10 min)
   - Create workflows for 707 ventures
   - 21,360 tasks per cycle
   - Assign to owners/teams

3. **Loop 3: Notion Sync** (15 min)
   - Keep all 707 venture pages current
   - Update properties and relationships
   - Embed ClickUp tasks

4. **Loop 4: Knowledge Graph** (5 min)
   - Analyze venture relationships
   - Find sister ventures
   - Map tech dependencies

5. **Loop 5: Revenue Ops** (continuous)
   - Score all 707 daily
   - Flag RED/YELLOW/GREEN
   - Create intervention tasks
