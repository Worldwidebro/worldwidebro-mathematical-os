## 🎯 DATABASE ALIGNMENT

### Supabase Schema Additions

```sql
-- Courses table
CREATE TABLE courses (
  course_id UUID PRIMARY KEY,
  venture_id UUID REFERENCES ventures(venture_id),
  title VARCHAR(255),
  sector VARCHAR(50),
  description TEXT,
  chapters JSONB,
  status VARCHAR(50),
  price_usd DECIMAL(10, 2),
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);

-- Enrollments table
CREATE TABLE course_enrollments (
  enrollment_id UUID PRIMARY KEY,
  course_id UUID REFERENCES courses(course_id),
  user_id UUID REFERENCES auth.users(id),
  status VARCHAR(50),
  joined_at TIMESTAMP,
  completed_at TIMESTAMP
);

-- Content table
CREATE TABLE course_content (
  content_id UUID PRIMARY KEY,
  course_id UUID REFERENCES courses(course_id),
  chapter_number INT,
  content_type VARCHAR(50),
  content_data JSONB,
  published_at TIMESTAMP
);

-- Skool integration log
CREATE TABLE skool_sync (
  sync_id UUID PRIMARY KEY,
  course_id UUID REFERENCES courses(course_id),
  skool_classroom_id VARCHAR(255),
  status VARCHAR(50),
  synced_at TIMESTAMP
);
```

### Venture Coverage Map
- ventures table (712 rows) → feeds into courses table
- Each sector gets 1-3 courses
- Courses linked to ventures via venture_id
- Enrollments track course adoption
