## Customer Acquisition Cost (CAC)

### Formula
```
CAC = (Advertising + Sales + Software) / New Customers Acquired
```

### Example: Real Estate CRM
```
Annual Channels:
  LinkedIn Ads:     $300/customer
  SEO/Organic:      $200/customer
  Referral Partners: $100/customer
  
Average CAC:       $200/customer
Payback Period:    $200 / $2,000 per month = 3.6 weeks (excellent)
```

### Healthy Ratio
```
CAC/LTV Target:    LTV should be 3x to 10x CAC

Real Estate Example:
  LTV = $48,000 (24 months at $2,000/month)
  CAC = $200
  Ratio = 240x (exceptional)
```

## Lead Scoring Algorithm

```
Score = (Industry Fit × 0.25) + (Company Size × 0.20) + 
        (Revenue × 0.20) + (Engagement × 0.20) + 
        (Urgency × 0.15)

Industry Fit:
  Perfect match = 100 pts
  Related = 50 pts
  Unrelated = 0 pts

Company Size:
  Ideal size = 100 pts
  Too small/big = 60 pts

Revenue:
  Can afford, not too large = 100 pts
  Borderline = 60 pts

Engagement:
  Demo attended = 100 pts
  Email opened = 10 pts
  Website visit = 5 pts

Urgency:
  Active outreach = 100 pts
  Organic interest = 50 pts

Result: Score 300+ = immediate sales priority
```
