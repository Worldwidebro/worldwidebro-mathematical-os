# Phase 1: FIN-036 Entity Formation Checklist

**Goal:** File Wyoming LLC, get EIN, open bank account  
**Timeline:** 2 hours + 24-48 hrs for approvals  
**Target:** 2026-06-12  

---

## Task 1.1: Prepare Documents (30 min)

- [ ] Business Name: "Arbitrage Nexus Platform LLC"
- [ ] Principal Place: Charlotte, NC
- [ ] Registered Agent: Antwuan Johns
- [ ] Operating Agreement: Single-page LLC governance document

---

## Task 1.2: File Wyoming LLC (15 min)

1. [ ] Go to: https://sos.wyo.gov/Business/Filings/
2. [ ] Select: "Articles of Organization for LLC"
3. [ ] Fill with exact business name + address
4. [ ] Pay: $100
5. [ ] **Save confirmation email**

**Approval:** 24 hours

---

## Task 1.3: Apply for EIN (15 min)

1. [ ] Go to: https://www.irs.gov/ein
2. [ ] Form: SS-4 (online)
3. [ ] Entity Type: LLC
4. [ ] Business Activity: "Deal Sourcing and Brokerage" (561730)
5. [ ] Submit

**Approval:** INSTANT (on screen)

---

## Task 1.4: Open Bank Account (30 min - 2 hrs)

**Option A: Mercury** (Recommended)
- Go to: https://mercury.com/business-account
- Upload: Operating Agreement + EIN screenshot
- Activate: Debit card

**Option B: Relay**
- Go to: https://relay.com
- Same process

**Required:** Wyoming LLC confirmation + EIN + Operating Agreement

---

## Task 1.5: Register SAM.gov (15 min approval, 1-2 days DUNS)

1. [ ] Go to: https://sam.gov
2. [ ] Get DUNS: https://www.dnb.com/duns-number/get-a-duns-number.html (FREE, 1-2 days)
3. [ ] Complete SAM.gov registration with DUNS
