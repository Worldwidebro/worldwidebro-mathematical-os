# 14-Layer Influence Model: Script Generation Template

For each venture, fill this template to generate systematic messaging across all platforms.

## Fill In These Basics First

```
VENTURE: [name]
CUSTOMER: [target segment]
PAIN: [their problem]
OUTCOME: [desired future state]
VALUE_DRIVER: [time|money|freedom|status|security]
OFFER: [what you sell]
```
