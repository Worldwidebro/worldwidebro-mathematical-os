## How Image #2 Applies Kardashian Principles to B2B Staffing

### 1. ONE BRAND SYSTEM

The design establishes **Worldwidebro Staffing** as the parent brand across all 8 email types.

**Consistent across all emails:**
- Logo placement (top-left, standardized size)
- Color palette: Dark blue (CTAs), teal (accents), green (success), orange (action), red (urgent)
- Typography: Sans-serif, high contrast, hierarchy clear
- Spacing: Generous padding, white space for breathing room
- Photography style: Professional workplace scenarios (not stock models, real teams)

**Not:** "Let's design a lead gen email today"  
**Yes:** "How does lead gen fit into the Worldwidebro brand system?"

### 4. IMAGE-FIRST STRATEGY (Selling Happens Visually)

**Not this:**
```
Subject: "We have candidates for your job opening"

Dear Hiring Manager,

We're pleased to inform you that we have 
screened 47 candidates for your Registered 
Nurse opening in Charlotte, NC.

Please review the attached document.
```

**This (Kardashian-style):**
```
┌─────────────────────────────────┐
│  [HERO: Photo of 3 confident    │
│   nurses in modern hospital]    │
├─────────────────────────────────┤
│  "TOP CANDIDATES READY FOR YOU" │
│                                 │
│  We matched top talent for your │
│  open position.                 │
│                                 │
│  → VIEW CANDIDATES              │
│                                 │
│  ✓ All qualified & interviewed  │
│  ✓ Available to start May 20    │
└─────────────────────────────────┘
```

**Why it works:**
- Image = Immediate recognition (these are the people you need)
- Headline = Clear value (candidates, not paperwork)
- Copy = Ultra-short (benefits only)
- CTA = One clear action

## Lead Gen Email Component System

### Base Structure (Reusable Across All 8 Types)

```
Header
  └─ Logo + Brand name + Tagline

Hero
  ├─ Photograph (vertical-specific)
  ├─ Headline (value prop)
  ├─ Subheadline (specific benefit)
  └─ Primary CTA button

Value Section
  ├─ Why choose us (3-4 bullets)
  ├─ How it works (process or proof)
  └─ Social proof or metrics

Secondary CTA
  └─ Learn more / Talk to specialist

Footer
  ├─ Contact info (phone + email)
  ├─ Manage preferences
  └─ Social links
```

### Lead Gen Campaign Sequence (5 Emails)

```
1. AWARENESS (Day 0)
   Subject: "Let's Build Stronger Teams Together"
   Image: Aspirational diverse team
   Goal: Signup

2. EDUCATION (Day 2)
   Subject: "How Worldwidebro Staffing Works"
   Image: Process flowchart or team
   Goal: Click to demo

3. SOCIAL PROOF (Day 5)
   Subject: "See What Our Clients Say"
   Image: Testimonial or data viz
   Goal: Click to case studies

4. URGENCY (Day 8)
   Subject: "Your Industry Needs Staffing Solutions Now"
   Image: Time-sensitive workplace scenario
   Goal: Click to "book demo"

5. CONVERSION (Day 12)
   Subject: "Ready to Build Your Team?"
   Image: Success/celebration photo
   Goal: Signup or demo request
```

## Design System Tokens

### Colors
```
Primary CTA (action):   #003366 (Navy)
Success CTA:            #2d8659 (Forest green)
Urgent CTA:             #c41e3a (Deep red)
Secondary CTA:          #0d9488 (Teal)
Highlight:              #f59e0b (Amber)
Neutral text:           #6b7280 (Gray)
```

### Typography
```
Logo:       24px bold, navy
Headline:   24px bold, charcoal
Subheadline: 16px regular, gray
Body:       15px regular, charcoal
Button:     14px bold, white
```

### Spacing
```
Padding:    48px top/bottom, 32px left/right
Component gap: 24px
Line height: 1.6
Max width:  600px
```

### Photography
```
✓ Real people (not stock models)
✓ Professional workplace settings
✓ Diverse teams
✓ Clear, bright lighting
✓ Action/doing moments
✗ Cliché stock photos
✗ Overly stylized
✗ Isolated people
```

1. **Consistent brand:** Same identity across all 8 types

3. **Vertical-specific:** Different images, same structure
4. **Data-driven:** Metrics prove value
5. **Image-first:** Visual selling, not dense copy
6. **Modular:** Agents assemble programmatically
7. **Campaign-focused:** Sequences, not one-off emails
