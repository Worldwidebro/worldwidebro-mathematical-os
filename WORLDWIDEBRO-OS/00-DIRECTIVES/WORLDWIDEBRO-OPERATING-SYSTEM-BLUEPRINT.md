## Executive Summary

Worldwidebro Holdings is a **multi-party incentive ecosystem** that scales from $10K/month (bootstrap) to $100K-150K/month (scale phase).

**Core Operating Model:**
- 6 core positions (CEO, COO, CFO, Chief Operator, Chief Originator, Infra Lead)
- Standardized deal flow (Referrer → Operator → Execution → Payment)
- Automatic revenue splits (costs 40%, referrer 10%, operator 35%, platform 10%, profit 5%)
- MCPs auto-generate contracts, route deals, distribute payments

**Key Insight:** You're not centralizing control. You're standardizing trust and enforcing fair splits at scale. Everyone gets paid from the same pool based on percentages defined upfront.

## Part 1: Organizational Structure

#### POSITION 1: CEO (You)
- **Equity:** 100% → dilutes with capital/hiring
- **Comp:** Founder equity + 2-5% profit bonus
- **Time:** 40-50 hrs/week

- **Reports:** CEO

#### POSITION 6: Infra Lead (VP Engineering/Platform)
- **Comp:** $80K-120K salary + 1-3% equity OR $3K-5K/month fractional
- **Time:** 40-50 hrs/week (build), 20-30 hrs/week (maintenance)

- **Direct reports:** Engineers (1-3 as you scale)
- **Responsibility:** MCPs, automation, data layer, system reliability

## Part 2: Deal Flow System

### Every Deal Has 4 Roles (Not 1)

1. **REFERRER (Originator)** — Brings the opportunity → Gets 5-20% of net revenue
2. **OPERATOR (Executor)** — Does the work → Gets 30-60% of project value
3. **CAPITAL PARTNER (Funder)** — Funds resources/capital → Gets 20-50% return or equity
4. **PLATFORM (You/System)** — Routes deals, enforces contracts → Gets 10-35% of revenue

### The Split Model

**Revenue: $100,000**
- Costs (delivery): 40% = $40,000
- Referrer fee: 10% = $10,000
- Operator payout: 35% = $35,000
- Platform (company): 10% = $10,000
- Profit buffer: 5% = $5,000

### Real Example: Ace Construction Website ($50K Deal)

| Day | Event | Details |
|-----|-------|---------|
| Day 1 | Referral submitted | Marco submits via system: "Ace Construction needs website + lead system" |
| Day 2 | Review & approval | CEO approves: "Yes, strategic fit with CON-011 ecosystem" → Assigns to Sarah |
| Day 3 | Contracts generated | MCP auto-generates 3 contracts (Referral, Operator, Client) → All sent for signature |
| Day 4 | Work begins | Sarah's team starts website build |
| Week 8 | Delivery complete | Sarah's team completes → Chief Operator verifies quality |
| Day 57 | Distributions | CFO processes payments: Marco ($5K), Sarah ($20K), Company ($5K), Costs ($20K) |
| Day 58 | Reputation updated | System updates reputation scores + marks deal as profitable |

## Part 3: Automation Layer

### What Gets Automated

**MCP 1: Contract Engine**
- Auto-generates contracts based on deal type
- Pulls referrer + operator info from database
- Sets percentages based on deal structure
- Output: PDF contracts ready to sign

**MCP 2: Deal Flow Router**
- Receives inbound referrals
- Validates against qualification criteria
- Routes to Chief Originator for review
- Output: Deal queue with priority scores

**MCP 3: Payment Distributor**
- Verifies delivery completion
- Calculates splits from deal contract
- Generates payment instructions
- Processes via ACH/wire
- Output: Payment receipts + audit trail

**MCP 4: Reputation Scorer**
- Tracks operator delivery quality
- Tracks referrer deal quality
- Tracks profitability per deal
- Updates trust scores in knowledge graph
- Output: Network health dashboard

### Workflows (n8n)

**Workflow 1: Daily Deal Intake**
- Runs every 4 hours
- Pulls new referrals from intake form
- Qualifies against criteria
- Notifies Chief Originator

**Workflow 2: Weekly Payment Run**
- Runs every Friday
- Pulls completed deals from week
- Calculates all splits
- Generates payment batch

**Workflow 3: Monthly Reporting**
- Runs 1st of month
- Aggregates all ventures' P&L
- Generates investor report
- Updates cap table
