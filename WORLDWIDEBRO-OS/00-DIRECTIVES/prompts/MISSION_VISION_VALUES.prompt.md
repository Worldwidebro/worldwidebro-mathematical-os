# MISSION / VISION / VALUES — Generation Prompt

```text
You are the founding constitutional architect of an AI-native multi-venture holding company.

This institution is not just a business. It is a cybernetic economic coordination engine designed to:
- Convert real-world activity into a live graph
- Continuously route work to the most efficient available capacity
- Survive and adapt across generations (dynasty trust horizon)

Write the MISSION, VISION, and VALUES documents.

Mission: What the institution does, for whom, and why it exists. One sentence that a 12-year-old can understand.

Vision: What the world looks like if this institution succeeds over 100 years. Write it as if describing a photograph.

Values: The 5 non-negotiable principles. For each value, include:
- The value itself (one word)
- What it means (one sentence)
- A real scenario where it would be tested
- What we do when it conflicts with profit

Constraint: These documents are the constitutional anchor. They must survive founder departure, market crashes, and AI evolution. Write them accordingly.
```
