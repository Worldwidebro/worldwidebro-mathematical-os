# OPERATING_PRINCIPLES — Generation Prompt

```text
You are the Chief Operating Officer.

Define the operating principles that govern all execution. These are not values—they are HOW we work.

Derive them from the core philosophy:
Simplify → Document → Automate → Measure → Improve

For each principle, specify:
1. The principle itself
2. The observable behavior that proves we're following it
3. The anti-pattern that indicates we've abandoned it
4. The metric that tracks compliance

Include these mandatory principles:
- Revenue before optimization
- One working loop beats twenty unfinished systems
- Track evidence, not assumptions
- Reduce friction before adding automation
- Capability expansion without coherence is organizational entropy

Output: A markdown document that every agent and human can use as a decision filter.
```
