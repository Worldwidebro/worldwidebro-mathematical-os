This folder contains the complete operating system for managing 704 ventures across 18 Operating Companies (OPCOs).

## What You Need to Know (5 min read)

### The Structure
- **1 Holding Company:** Worldwidebro Holdings
- **18 Operating Companies:** Verticals by sector
- **704 Ventures:** Individual revenue units assigned to OPCOs
- **10 Horizontal Functions:** Shared services across all OPCOs

### The Model
Each venture follows a **6-stage lifecycle:** Idea → Research → Building → Launching → Operating → Scaling

Every 90 days: **Keep / Scale / Sell / Merge / Pause / Archive**

### The Tool
**Airtable dashboard** is the command center (single source of truth)
