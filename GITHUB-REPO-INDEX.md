## 📊 REPO STRUCTURE (What's Inside Each Repo)

### **Standard Venture Repo:**
```
https://github.com/Worldwidebro/[venture-id]-[venture-name]/
├── README.md              ← Project overview, setup instructions
├── SKILL.md               ← Capabilities, metadata, integrations
├── CLAUDE.md              ← AI operational guide (top 10 ventures)
├── package.json           ← Dependencies (Node.js projects)
├── app/ or src/           ← Source code
├── supabase/              ← Database migrations
├── docs/                  ← Additional documentation
└── .github/               ← GitHub Actions workflows
```

### **Example: BW-001**
```
https://github.com/Worldwidebro/bw-001-lash-extension-studio/
├── README.md              ← Lash studio booking platform
├── SKILL.md               ← Beauty & wellness capabilities
├── package.json           ← Next.js, TypeScript, Tailwind
├── app/                   ← Next.js app router
│   ├── booking/           ← Booking flow
│   ├── stylist/           ← Stylist dashboard
│   └── client/            ← Client dashboard
├── supabase/              ← Database schema
└── docs/                  ← Business docs
```
