CONTROL PLANES:

CP-013: Knowledge (Neo4j + Qdrant)
├─ Entities, relationships, evidence
├─ Semantic search + retrieval
└─ Organizational ontology

CP-031: Intelligence (Comp AI CRM)
├─ Research agents
├─ Evidence ledger
└─ Entity enrichment

CP-032: Business Operations (Twenty)
├─ Companies, people, deals
├─ Custom objects
└─ Workflow automation

CP-033: Execution (ClickUp)
├─ Tasks, projects, goals
├─ Accountability tracking
└─ Work distribution

CP-028: Collaboration (Buzz)
├─ Human-agent rooms
├─ Decision threads
└─ Event relay

CP-034: Engineering (GitHub)
├─ Repositories
├─ Code + CI/CD
└─ Issues

CP-006: Agents (Orchestration)
├─ Routing + scheduling
├─ Tool access control
└─ Context assembly

CP-007: Models (OmniRoute)
├─ Model routing
├─ Fallback strategies
└─ Cost tracking

      ↓

      ↓
Results Tracked in Neo4j
      ↓
Weekly Health Checks (AGT-018)


EXAMPLE FLOW: Company Discovery

Comp AI Agent runs nightly
  │
  ├─ Researches "Company X expanding into healthcare"
  └─ Records evidence: timestamp, source, confidence level
       │
       ▼
Neo4j Updated
  │
  ├─ Company X -[EXPANDED_INTO {evidence}]-> Healthcare
  └─ Webhook fires
       │
       ▼
Twenty Updated
  │
  ├─ Company.industries += "Healthcare"
  ├─ Workflow triggered: "Healthcare entry = opportunity"
  └─ Creates Deal: "Evaluate healthcare market fit for LT-005"
       │
       ▼
ClickUp Project Auto-Created
  │
  ├─ Project: "Company X - Healthcare Opportunity"
  ├─ Task 1: Market analysis (due Sep 13)
  ├─ Task 2: Product fit evaluation (due Sep 15)
  ├─ Task 3: Revenue projection (due Sep 17)
  └─ Task 4: Decision & outreach (due Sep 20)
       │
       ▼
Buzz Notification
  │
  ├─ #research-ventures: "Healthcare opportunity identified"
  ├─ #company-x-deal: "New project created"
  └─ @sales-team: "Action required by Sep 20"
       │
       ▼
Agent/Human Executes
  │
  ├─ Reads ClickUp task
  ├─ Reads Neo4j context (why this matters)
  ├─ Reads Twenty deal details
  ├─ Executes (research, analyze, decide)
  └─ Updates ClickUp + Buzz
       │
       ▼
Neo4j Updated (closes loop)
  │
  └─ LT-005 -[QUALIFIED_OPPORTUNITY]-> Company X

KEY INSIGHT:

This is not "CRM A", "CRM B", "Chat App".

This is:
  - A research system (Comp AI)
  - A business record system (Twenty)
  - A work accountability system (ClickUp)
  - A collaboration fabric (Buzz)
  - A knowledge graph (Neo4j + Qdrant)
  - An engineering platform (GitHub)

All synchronized. All feeding the same Neo4j.

That creates a genuine agentic operating system.
