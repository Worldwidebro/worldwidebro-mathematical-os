# Company Brain Decision Engine (`_TOOLS/decision-engine`)

High-speed typed decision and reflex layer for **Company Brain** and **GBrain**.

## Capabilities
1. **`gbrain` Skill Resolver:** Resolves natural language user intents to one of GBrain's 73 skills without requiring exact keyword matches.
2. **Ambient Signal Detector:** Evaluates inbound turns in sub-10ms for original thinking, architectural rules, and entity mentions, automatically scoring signal strength to trigger PGLite memory writebacks.
3. **Laya-Compatible Typed Decisions:** Implements `Choice`, `Score`, and `Noul` (boolean) decisions with calibrated confidence estimation.
