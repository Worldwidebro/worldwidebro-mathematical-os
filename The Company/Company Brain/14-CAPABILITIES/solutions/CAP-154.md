# CAP-154: Container Hardening & Rootless Execution

> **Authority:** System Architecture & Capability Control Plane (CP-027)  
> **Sector:** [[SECTORS/SEC-026-utilities-infrastructure|SEC-026-utilities-infrastructure: Utilities & Infrastructure]]  
> **Status:** ACTIVE — Audited 2026-09-06  
> **Category:** Tier 5: Cybersecurity & Zero Trust Architecture

---

## 1. Overview & Scope
Run containers with non-root users, read-only root filesystems, and stripped Linux capabilities.

---

## 2. Problem Statement
Ventures operating without `CAP-154` typically encounter:
- Container escape vulnerabilities granting attackers full host node root access
- Malicious modification of system binaries inside running containers
- Inability to pass PCI-DSS or SOC 2 container security audits

---

## 3. Solution Space & Reference Tooling
Recommended tooling from internal platforms and the 904 Starred External Capability Universe:
- **Docker Rootless**
- **Distroless Images**
- **Podman**
- **AppArmor**
- **SELinux**
