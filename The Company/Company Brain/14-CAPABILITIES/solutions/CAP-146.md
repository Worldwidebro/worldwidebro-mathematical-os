# CAP-146: Secret Scanning & Automated Credential Hygiene

> **Authority:** System Architecture & Capability Control Plane (CP-027)  
> **Sector:** [[SECTORS/SEC-033-cybersecurity-privacy|SEC-033-cybersecurity-privacy: Cybersecurity & Privacy]]  
> **Status:** ACTIVE — Audited 2026-09-06  
> **Category:** Tier 5: Cybersecurity & Zero Trust Architecture

---

## 1. Overview & Scope
Detect committed secrets, cloud API keys, and private tokens in source code repositories before merge.

---

## 2. Problem Statement
Ventures operating without `CAP-146` typically encounter:
- Leaked AWS or OpenAI keys leading to tens of thousands in unauthorized usage within hours
- Revocation scrambles during security emergencies
- Public exposure of internal database passwords in git history

---

## 3. Solution Space & Reference Tooling
Recommended tooling from internal platforms and the 904 Starred External Capability Universe:
- **Gitleaks**
- **TruffleHog**
- **GitHub Secret Scanning**
- **GitGuardian**
- **Semgrep Secrets**
