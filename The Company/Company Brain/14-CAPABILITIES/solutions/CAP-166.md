# CAP-166: Virtual Private Cloud (VPC) & Network Segmentation

> **Authority:** System Architecture & Capability Control Plane (CP-027)  
> **Sector:** [[SECTORS/SEC-026-utilities-infrastructure|SEC-026-utilities-infrastructure: Utilities & Infrastructure]]  
> **Status:** ACTIVE — Audited 2026-09-06  
> **Category:** Tier 5: Cybersecurity & Zero Trust Architecture

---

## 1. Overview & Scope
Isolate backend workloads into private subnets with strict security group egress/ingress rules.

---

## 2. Problem Statement
Ventures operating without `CAP-166` typically encounter:
- Direct internet routability to production database and cache instances
- Breach of a single staging server exposing production network traffic
- Lack of visibility into cross-service packet flows and network boundaries

---

## 3. Solution Space & Reference Tooling
Recommended tooling from internal platforms and the 904 Starred External Capability Universe:
- **AWS VPC**
- **Terraform VPC Modules**
- **Cilium Network Policies**
- **Calico CNI**
- **WireGuard Subnets**
