# CAP-131: OpenAPI Automated Code Generation

> **Authority:** System Architecture & Capability Control Plane (CP-027)  
> **Sector:** [[SECTORS/SEC-024-technology-software|SEC-024-technology-software: Technology & Software]]  
> **Status:** ACTIVE — Audited 2026-09-06  
> **Category:** Tier 4: Software Engineering & Delivery

---

## 1. Overview & Scope
Generate type-safe client SDKs and server stubs directly from OpenAPI v3 interface specifications.

---

## 2. Problem Statement
Ventures operating without `CAP-131` typically encounter:
- Frontend developers manually hand-coding API fetch calls with inaccurate types
- Client and server code drifting out of sync after backend updates
- Weeks wasted hand-crafting multi-language API SDKs for third-party partners

---

## 3. Solution Space & Reference Tooling
Recommended tooling from internal platforms and the 904 Starred External Capability Universe:
- **OpenAPI Generator**
- **Orval**
- **Hey-API (ts-rest)**
- **Fern**
- **Kiota (Microsoft)**
