## 1. Overview & Scope
Enforce clean code conventions, detect dead code, and prevent common anti-patterns automatically.

## 2. Problem Statement
Ventures operating without `CAP-123` typically encounter:
- Endless, unproductive stylistic arguments in GitHub pull request reviews
- Subtle bugs arising from loose type coercion and unhandled null values
- Degraded code maintainability across diverse contributors
