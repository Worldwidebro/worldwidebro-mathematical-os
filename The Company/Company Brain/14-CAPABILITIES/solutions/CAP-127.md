# CAP-127: Polyglot Monorepo Architecture & Build Caching

> **Authority:** System Architecture & Capability Control Plane (CP-027)  
> **Sector:** [[SECTORS/SEC-024-technology-software|SEC-024-technology-software: Technology & Software]]  
> **Status:** ACTIVE — Audited 2026-09-06  
> **Category:** Tier 4: Software Engineering & Delivery

---

## 1. Overview & Scope
Manage multiple interconnected packages, apps, and libraries within a single repository with shared tooling.

---

## 2. Problem Statement
Ventures operating without `CAP-127` typically encounter:
- Tedious multi-repo cross-publishing workflows delaying feature releases
- Duplicate build steps wasting hours of developer and CI machine time
- Version skew between frontend web apps and backend shared API types

---

## 3. Solution Space & Reference Tooling
Recommended tooling from internal platforms and the 904 Starred External Capability Universe:
- **Turborepo**
- **Nx**
- **Bazel**
- **Pnpm Workspaces**
- **Lerna**
