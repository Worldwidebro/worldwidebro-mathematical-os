## 1. Overview
Skills provide specialized, executable domain procedural instructions and behavioral personas to autonomous agents operating in Company Brain. Every skill is defined in its own directory with a `SKILL.md` file carrying structured YAML frontmatter, execution heuristics, quality gates, and technical deliverables.
