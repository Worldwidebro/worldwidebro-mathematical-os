## 1. Infrastructure Subsystems (12 Domains)
The primary operational core of `56-ENGINEERING` is organized into 12 structured engineering domains:

1. **[[56-ENGINEERING/INFRASTRUCTURE/01_CORE/INFRASTRUCTURE|01_CORE]]** — Core architecture, OS specifications, metamodel, and audited reality.
2. **[[56-ENGINEERING/INFRASTRUCTURE/02_COMPUTE/COMPUTE|02_COMPUTE]]** — Compute units (Mac Studio M4 Max, MacBook Air M-Series, Vercel Edge).
3. **[[56-ENGINEERING/INFRASTRUCTURE/03_STORAGE/STORAGE|03_STORAGE]]** — Tiered storage architecture (Internal SSDs, LaCie 4TB, Samsung T7 Shield 2TB, Cold Archive).
4. **[[56-ENGINEERING/INFRASTRUCTURE/04_NETWORK/NETWORK|04_NETWORK]]** — Tailscale WireGuard mesh (`100.64.0.0/10`), MagicDNS, strict port bindings.
5. **[[56-ENGINEERING/INFRASTRUCTURE/05_CLOUD/CLOUD|05_CLOUD]]** — Hybrid cloud edge, 95 Vercel venture sites, multi-cloud exit strategy.
6. **[[56-ENGINEERING/INFRASTRUCTURE/06_DATA/DATABASES|06_DATA]]** — Polyglot persistence (Neo4j graph, Qdrant vectors, PostgreSQL 16, Redis, MinIO S3).
7. **[[56-ENGINEERING/INFRASTRUCTURE/07_RUNTIME/RUNTIME|07_RUNTIME]]** — Container runtimes (Docker context `macstudio`), LiteLLM, OmniRoute, MLX.
8. **[[56-ENGINEERING/INFRASTRUCTURE/08_DEPLOYMENT/DEPLOYMENT|08_DEPLOYMENT]]** — NIST SP 800-204C DevSecOps pipeline, IaC, PaC, OaC separation.
9. **[[56-ENGINEERING/INFRASTRUCTURE/09_OBSERVABILITY/OBSERVABILITY|09_OBSERVABILITY]]** — Grafana dashboards (:3011), Langfuse (:3003), OpenObserve (:5080), telemetry.
10. **[[56-ENGINEERING/INFRASTRUCTURE/10_SECURITY/SECURITY-INFRASTRUCTURE|10_SECURITY]]** — NIST SP 800-207 Zero Trust, Bitwarden JIT secrets (`SEC-BITWARDEN-001`), RBAC/ABAC.
11. **[[56-ENGINEERING/INFRASTRUCTURE/11_RESILIENCE/RESILIENCE|11_RESILIENCE]]** — 3-2-1 backup strategy, disaster recovery runbooks, automated failover, RTO/RPO.
12. **[[56-ENGINEERING/INFRASTRUCTURE/12_COST-GOVERNANCE/INFRASTRUCTURE-COST|12_COST-GOVERNANCE]]** — FinOps governance ($309/mo TCO), capacity headroom, ADRs 001–005.
