## Part 2: Master Orchestrator Logic

The **Master Orchestrator** runs on Company Brain and makes decisions by querying:

```
DECISION FLOW

Agent needs to decide:
  "Should we invest in Venture X?"
  "What's the priority for capital allocation?"
  "Is Venture A ready to scale?"

    ↓

Agent queries Company Brain:
  1. Neo4j: Venture X relationships + dependencies
  2. Supabase: Venture X metrics + financials
  3. Qdrant: Similar ventures + patterns
  4. Asset graph: Available capital + constraints

    ↓

Agent runs Decision Logic:
  - Readiness score (from metrics)
  - Competitive position (from patterns)
  - Capital available (from asset graph)
  - Risk tolerance (from policy)
  - Timeline (from roadmap)

    ↓

Agent produces Recommendation:
  "Invest $X in Venture Y, contingent on Z"
  with reasoning + alternatives

    ↓

Human approval (if required):
  CEO Agent → CEO (human) → Board (if needed)

    ↓

Execution:
  Finance Agent → Fund transfer
  Ops Agent → Resource allocation
  Tech Agent → Infrastructure provision

    ↓

Monitoring:
  Agents track performance vs. forecast
  Alert if thresholds breached
  Escalate if intervention needed
```
