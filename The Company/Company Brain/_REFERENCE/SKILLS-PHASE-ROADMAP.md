## QUICK DECISION TREE

**Use this to find the right skill:**

```
Is it a new idea/project?
├─ Yes → /gsd-new-project
└─ No → next question

Do you need to validate the problem?
├─ Yes → /office-hours or /gsd-explore
└─ No → next question

Do you need to plan/spec something?
├─ Yes → /spec or /gsd-plan-phase
└─ No → next question

Do you need to design (UI/UX/Architecture)?
├─ Yes → /design-consultation or /plan-eng-review
└─ No → next question

Do you need to write/implement code?
├─ Yes → /gsd-execute-phase or /gsd-fast
└─ No → next question

Do you need to test/QA?
├─ Yes → /qa or /gsd-code-review
└─ No → next question

Do you need to ship/deploy?
├─ Yes → /ship or /land-and-deploy
└─ No → next question

Do you need to debug/investigate?
├─ Yes → /investigate or /gsd-forensics
└─ No → /gsd-health (general health check)
```
