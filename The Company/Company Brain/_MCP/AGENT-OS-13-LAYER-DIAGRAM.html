🌳 Venture Decision Tree (How Agents Route to Work)

Venture: OPS-001 (Staffing)
Stage: Growth | Revenue: $2.5K (1 placement) | Team: 3 agents
Decision 1: What drives revenue?
→ Cold calls → Job orders → Candidate delivery → Payment
Decision 2: What's bottleneck?
→ Cold calls (only 2 made) → Assign Revenue Agent (call more)
Decision 3: Who executes?
→ Revenue Agent (core) + Cold-caller specialist (Layer 13) + Closer specialist
→ Context: 10 past calls, 1 success, success rate 10% → optimize objection handling
Decision 4: What tools needed?
→ Supabase (prospect list), Stripe (payment recording), Slack (notifications)
Decision 5: What authority?
→ Revenue Agent: Can decide prospect priority, email content
→ Can't decide: Pricing, partnerships, hiring → Escalate to CEO/CFO

Neo4j Integration

Query Pattern: Find agents for cold-calling
MATCH (a:AGENT) -[:PROVIDES]-> (c:CAPABILITY {name: "cold-calling"}) RETURN a
Query Pattern: Audit agent decisions
MATCH (e:EXECUTION) -[:RECORDED_BY]-> (a:AGENT) WHERE e.timestamp > date RETURN e.result, a.name
Query Pattern: Venture team assignment
MATCH (v:VENTURE {id: "OPS-001"}) -[:CONTROLLED_BY]-> (cp:CONTROL_PLANE) -[:ASSIGNS]-> (a:AGENT)
Learning Loop: Execution → Success/Fail → Context Updated → Next Agent Smarter

Qdrant Integration

Vector Type: Execution outcomes
"cold_call_with_electrician_placement_success" → embedding → semantic search
Similarity Query: "Find past cold calls similar to this prospect"
→ Returns 10 past calls with context + success rates
Context Assembly: For new agent, subgraph pulls:
- Top 5 similar executions (by vector similarity)
- Their outcomes + metrics
- Success patterns
Learning: Each execution adds vector → repository grows → future agents smarter

✨ Key Architecture Insight

Problem: 789 ventures can't each have 100 permanent agents = 78,900 agents (impossible to manage, coordinate, cost)

Solution: 246 dynamic agents (16 core + 230 specialists) + Neo4j orchestrator + Qdrant memory

How it works: Venture needs revenue → Orchestrator queries Neo4j → "What agents know cold-calling?" → Assembles team (Revenue Agent + Cold-Caller Specialist + Closer) with context (past calls + success rate) → Executes in parallel → Records outcome → Next venture learns from it

Result: Each agent gets smarter with every venture execution. Agents scale across all 789 ventures with learning compounding.
