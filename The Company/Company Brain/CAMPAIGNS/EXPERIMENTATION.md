## 1. Scientific Method in Commercial Execution

Campaigns are treated as empirical scientific laboratories. We never guess; we formulate falsifiable hypotheses and run controlled experiments.

Every experiment must define:
$$\text{If } [\text{Variable } X], \text{ then } [\text{Result } Y], \text{ because } [\text{Causal Mechanism } Z]$$

---

## 2. Active Experiment: EXP-001

- **Name:** Outbound Hook Differentiation: Dollar Cost vs Security Airgap
- **Hypothesis:** Leading with quantifiable monthly dollar waste ("$15k/mo Claude bills") will generate a \(\ge 50\%\) higher positive reply rate than leading with security airgap compliance among Series A AI startups.
- **Sample Size:** 200 accounts (100 per arm).
- **Statistical Threshold:** \(p < 0.05\) (two-tailed z-test for proportions).
