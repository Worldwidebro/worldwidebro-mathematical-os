## 1. The Strict Qualification Rubric

An account is classified as **ICP** for `CAM-001` if and only if it meets all 5 criteria:

| Parameter | ICP Threshold | Disqualification Rule |
| :--- | :--- | :--- |
| **Team Size** | 10 to 60 software engineers | < 5 engineers (too small) or > 250 engineers (procurement stall). |
| **API Spend** | > $5,000 / month in LLM API bills | < $2,000 / month (ROI math will not trigger urgency). |
| **Tool Adoption** | Active users of Claude Code, Cursor, Copilot, or LangGraph | Zero AI assistant usage in developer workflow. |
| **Funding / Stage** | Seed, Series A, Series B, or Profitable Bootstrapped | Pre-seed or pre-revenue with zero cash reserves. |
| **Decision Speed** | Able to approve a $7,500 diagnostic SOW in < 7 days | Requires multi-month RFP or procurement committee. |
