## 1. Single-Threaded Ownership Principle

Every campaign must have exactly **ONE** designated Single-Threaded Owner (`OWN-001`) who holds ultimate accountability for the primary objective and capital deployment.

---

## 2. Functional Ownership Breakdown

| Functional Area | Designated Role / Agent | Accountabilities |
| :--- | :--- | :--- |
| **Campaign Owner** | Sovereign Operator (`PPL-001`) | Primary objective attainment, ROI, kill decisions. |
| **Creative Owner** | Creative Director Agent (`AGT-CRE-001`) | Copywriting standards, visual assets, message fidelity. |
| **Media Owner** | Outbound Strategist (`AGT-OUT-001`) | Deliverability, list hygiene, pacing, send volume. |
| **Sales Owner** | Deal Strategist (`AGT-DEA-001`) | Discovery calls, MEDDPICC qualification, SOW closes. |
| **Data Owner** | Analytics Agent (`AGT-DAT-001`) | Webhook integrity, Grafana dashboards, attribution. |
| **Finance Owner** | Commercial Escrow Officer (`PPL-001`) | Deposit verification, invoice generation, refunds. |
| **Tech Owner** | System Architect (`CP-027`) | 48-Hour audit execution, Neo4j graphs, MLX benchmarks. |
