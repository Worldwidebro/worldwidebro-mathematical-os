## 1. The 4 Acute Pains of Enterprise Agentic Coding

Every communication in `CAM-001` addresses one of four quantified engineering headaches:

### Pain 1: The Context Window Tax (Monorepo Token Burn)
AI coding assistants dump 100,000+ tokens of raw file context and build logs into prompt windows to answer a simple 5-line bug fix. Engineering teams burn **$15k to $40k/mo** purely on repetitive token ingestion overhead.

### Pain 2: The Agent Hallucination Spiral
Because LLMs receive unstructured context dumps rather than precise AST relational subgraphs, agents hallucinate missing dependencies, overwrite working code, and require multiple expensive retry loops.

### Pain 3: Intellectual Property & Compliance Terror
Enterprise legal and SOC2 auditors forbid developers from using public cloud LLM endpoints on customer data schemas, leaving developers frustrated without modern AI tools.

### Pain 4: API Rate Limits & Provider Fragility
When OpenAI or Anthropic suffers an outage or throttles API quotas during a sprint, the entire engineering organization grinds to a halt.
