## 1. Empirical Insights from Engineering Field Telemetry

- **Insight 1 (Token Redundancy):** Across typical Python and TypeScript coding agent sessions, between 58% and 74% of consumed tokens consist of duplicated terminal stack traces, node_modules definitions, and unpruned file headers.
- **Insight 2 (Developer Resistance to New UIs):** Developers refuse to abandon Cursor or Claude Code in favor of proprietary web portals; optimization must happen invisibly at the proxy/routing layer.
- **Insight 3 (Sovereignty Trigger):** Enterprise clients are beginning to demand contractual proof that their vendor does not transmit source code to external foundation model providers.
