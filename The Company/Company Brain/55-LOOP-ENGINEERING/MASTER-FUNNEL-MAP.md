# MASTER FUNNEL MAP

> **Scope:** Full Funnel Inventory for the Company Brain / Venture OS
> **Authority:** 55-LOOP-ENGINEERING / CP-027

This document defines the complete lifecycle and state transitions for all operations within the portfolio. It structures the 447 operational funnels into 17 unified families that power the **Universal Enterprise Loop**.

## The Enterprise OS Loop
> **Discover → Build/Buy → Finance → Operate → Measure → Harvest → Reinvest**

---

## The 17 Funnel Families (The Master Spine)
These families act as the top-level spine for the Company Brain / IZA OS, allowing every venture to plug its specialized funnels into a shared architecture.

| Family | Core Movement |
| :--- | :--- |
| **Demand** | Market → Prospect |
| **Sales** | Prospect → Customer |
| **Commerce** | Customer → Transaction |
| **Fulfillment** | Transaction → Delivery |
| **Finance** | Delivery → Cash |
| **Retention** | Customer → Repeat Customer |
| **Growth** | Customer → More Customers |
| **Product** | Problem → Product → Adoption |
| **Operations** | Request → Completed Work |
| **Data** | Signal → Intelligence |
| **AI** | Task → Agent → Action → Result |
| **Talent** | Person → Role → Work |
| **Partner** | Partner → Integration → Revenue |
| **Capital** | Opportunity → Capital → Return |
| **Venture** | Idea → Revenue → Profit → Scale |
| **Harvest** | Asset → Exit → Capital |
| **Reinvestment** | Capital → Next Opportunity |
