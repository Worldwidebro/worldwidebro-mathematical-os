# 1. Curriculum Planning

Create detailed course outline, learning objectives, and content structure.

## Input
- Topic (from ClickUp task or document upload)
- Target audience
- Duration (hours)
- Learning outcomes expected

## Process
1. Extract key concepts from topic/document
2. Organize into learning progression
3. Define learning objectives per module
4. Create outline with time allocations
5. Identify required media (images, videos, interactives)

## Output
Curriculum document with:
- Course overview
- Module breakdown (5-10 modules)
- Learning objectives per module
- Estimated time per section
- Key concepts and terminology
- Resource requirements

## Validation
- At least 3 distinct learning objectives
- Clear progression from simple to complex
- Time estimates sum to total course duration
