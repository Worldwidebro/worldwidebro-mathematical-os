# 4. Interactive Design

Create simulations, games, and PBL activities.

## Input
- Course content
- Learning objectives
- Key concepts to practice

## Process
1. Identify simulation opportunities (experiments, scenarios)
2. Design interactive exercises (drag-drop, code playgrounds)
3. Create project-based learning activities
4. Generate HTML/Canvas specifications
5. Define interaction logic

## Output
- 3-5 interactive elements per course
- Simulation specs with parameters
- PBL project rubrics
- HTML template specifications

## Validation
- At least 1 interactive per 10 slides
- All have learning objective alignment
- Technical feasibility confirmed
