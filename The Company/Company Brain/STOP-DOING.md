## 1. Absolute Injunctions (Zero Tolerance)

1. **STOP building infrastructure before having paying customers.**  
   *No new database containers, no new microservices, and no new ontology schemas until customer cash is collected.*
2. **STOP cataloging repositories and entities as a substitute for execution.**  
   *Ingesting another 500 GitHub repos into Neo4j does not increase enterprise value. Shipping a product does.*
3. **STOP running duplicate Docker stacks.**  
   *Never run multiple overlapping database instances on the same host.*
4. **STOP configuring proxy translation layers for tools that are not in active daily use.**  
   *Do not spend afternoons debugging proxy routes for CLIs you are not using.*
5. **STOP using imperial and Fortune-10 corporate jargon in solo founder documents.**  
   *Banish "50 sovereign control planes" and "enterprise holding conglomerate." Speak in terms of: Offer, Leads, Customers, Cash, and Code.*
6. **STOP starting new ventures because finishing the current one feels mundane.**  
   *A new venture is forbidden from being registered until the current top venture has either reached $10k/mo MRR or been formally terminated via kill criteria.*
7. **STOP penny-pinching compute while ignoring high-ticket sales.**  
   *Spending 4 hours saving $0.02 on local inference while ignoring a $5,000 commercial proposal is financial insanity.*
8. **STOP keeping dead code alive out of emotional attachment to past effort.**  
   *Sunk cost is not an asset. Delete obsolete branches, containers, and prototypes without sentimentality.*
