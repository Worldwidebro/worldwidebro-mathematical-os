## The distinctions are important

These terms are often casually mixed together, but they perform different cognitive functions:

| Artifact          | Primary function                           |
| ----------------- | ------------------------------------------ |
| **Dictionary**    | Defines terms                              |
| **Glossary**      | Defines terms within a domain/document     |
| **Lexicon**       | Collection of terms/expressions            |
| **Thesaurus**     | Maps semantic relationships                |
| **Encyclopedia**  | Explains bodies of knowledge               |
| **Index**         | Points from concepts/terms to locations    |
| **Catalog**       | Describes and organizes a collection       |
| **Directory**     | Locates entities/resources                 |
| **Registry**      | Authoritative record of entities           |
| **Register**      | Formal recorded list                       |
| **Ledger**        | Persistent record of transactions/events   |
| **Roster**        | List of members/participants               |
| **Bibliography**  | Maps literature/sources                    |
| **Archive**       | Preserves historical material              |
| **Repository**    | Stores artifacts/resources                 |
| **Ontology**      | Represents entities and relationships      |
| **Taxonomy**      | Classifies entities hierarchically         |
| **Schema**        | Defines structural/data representation     |
| **Framework**     | Organizes reasoning/action                 |
| **Model**         | Represents how something works             |
| **Map**           | Represents relationships/territory         |
| **Graph**         | Represents nodes + relationships           |
| **Handbook**      | Practical reference                        |
| **Manual**        | Instructions for operation                 |
| **Playbook**      | Repeatable strategic/operational responses |
| **SOP**           | Standardized procedure                     |
| **Protocol**      | Defined interaction/process rules          |
| **Specification** | Defines required characteristics           |
| **Report**        | Communicates findings                      |
| **Paper**         | Formal scholarly/technical argument        |
| **Case study**    | Detailed examination of an instance        |
| **Memo**          | Focused communication/analysis             |
| **Journal**       | Sequential record/reflection               |
| **Notes**         | Captured knowledge                         |
| **Curriculum**    | Structured learning sequence               |
| **Reading path**  | Ordered route through knowledge            |

# The really powerful addition: `[[KNOWLEDGE_ARTIFACT_LIFECYCLE]]`

```text
[[OBSERVATION]]
      ↓
[[NOTE]]
      ↓
[[DOCUMENT]]
      ↓
[[REFERENCE]]
      ↓
[[INDEX]]
      ↓
[[CATALOG]]
      ↓
[[CLASSIFICATION]]
      ↓
[[ONTOLOGY]]
      ↓
[[REGISTRY]]
      ↓
[[KNOWLEDGE_GRAPH]]
      ↓
[[READING_PATH]]
      ↓
[[UNDERSTANDING]]
      ↓
[[REASONING]]
      ↓
[[DECISION]]
      ↓
[[ACTION]]
      ↓
[[OUTCOME]]
      ↓
[[EVIDENCE]]
      ↓
[[NEW_KNOWLEDGE]]
```

That gives you something much deeper than a collection of Markdown files.

You're effectively building a **machine-readable library of reality** where:

* `[[DICTIONARY]]` tells the system **what things mean**
* `[[TAXONOMY]]` tells it **what category things belong to**
* `[[ONTOLOGY]]` tells it **how things relate**
* `[[REGISTRY]]` tells it **what actually exists**
* `[[INDEX]]` tells it **where information can be found**
* `[[CATALOG]]` tells it **what the collection contains**
* `[[LIBRARY]]` tells it **how knowledge is organized**
* `[[ARCHIVE]]` tells it **what existed historically**
* `[[READING_ORDER]]` tells it **what should be understood first**
* `[[THINKING_FRAMEWORKS]]` tells it **how to reason about it**
* `[[QUESTION_ONTOLOGY]]` tells it **what remains unknown**
* `[[EVIDENCE]]` tells it **what supports the claims**
* `[[KNOWLEDGE_GRAPH]]` tells it **how everything connects**
* `[[SOURCE_OF_TRUTH]]` tells it **which representation has authority**
* `[[REALITY]]` tells it **what has actually been verified**

And the meta-layer becomes:

```text
[[INDEX_OF_INDEXES]]
       ↓
[[CATALOG_OF_CATALOGS]]
       ↓
[[REGISTRY_OF_REGISTRIES]]
       ↓
[[ONTOLOGY_OF_ONTOLOGIES]]
       ↓
[[TAXONOMY_OF_TAXONOMIES]]
       ↓
[[GRAPH_OF_GRAPHS]]
       ↓
[[KNOWLEDGE_OF_KNOWLEDGE]]
       ↓
[[META_KNOWLEDGE]]
```
