## 1. Pipeline Overview
The **Learning Pipeline** serves as stage 09 of Company Brain's 10-stage cognitive data pipeline.

Harvests run receipts, measures outcome success against initial goals, detects execution anomalies, updates few-shot prompt libraries, and refines operational heuristics.
