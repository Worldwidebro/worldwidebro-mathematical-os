# Control Plane 031: Security, Cryptographic Trust & Identity

**Authority Scope:**
- Cryptographic key management and identity assertion across all nodes.
- Zero-Trust network verification across Tailscale mesh.
- Autonomous agent authorization gates and execution guardrails.
- SOC 2, HIPAA, and ISO compliance evidence gathering.

### Governance Directives
1. **Verification Before Action:** Every agent command mutating production state must pass reality verification gates.
2. **Deterministic Audit Logs:** Every deployment and execution emits structured receipts to `receipts/` and `_MEMORY/`.
3. **Data Segregation:** Operating company user data is strictly segregated from holding company registries and family trust assets.
