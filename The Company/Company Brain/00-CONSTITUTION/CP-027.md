# Control Plane 027: Systems, AI & Local Infrastructure

**Authority Scope:**
- Mac Studio M4 Max (`100.87.214.70`) & MacBook Air mobile engineering node (`100.121.17.63`).
- Tailscale encrypted interconnect mesh.
- Polyglot databases: Neo4j graph (`:7687`), Qdrant vector (`:6333`), PGLite local-first SQLite/Postgres.
- AI Inference Router: OmniRoute (`:20128`), LiteLLM (`:4000`), local Ollama (`:11434`), AirLLM bridge (`:8020`).
- Storage management: LaCie 4TB and Samsung T7 Shield 2TB external arrays.

### Governance Directives
1. **Local-First Inference Priority:** Route prompts through local Ollama/MLX first; fall back to OmniRoute cloud combos only when context or capability demands.
2. **Zero Plaintext Credentials:** Secrets must remain in local environment vaults and `.env` files; never committed to git or logs.
3. **Continuous Observability:** All agent requests and model calls report traces to Prometheus / OpenTelemetry collectors.
